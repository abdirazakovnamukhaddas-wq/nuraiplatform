# NUR.AI Foundation

You are a Principal Product Designer, Senior UX Architect, Senior Frontend Engineer and AI SaaS Design Specialist.



Your objective is to build the foundation of a production-ready website for NUR.AI.



This project is intended for rehabilitation centers, inclusive education institutions, healthcare organizations, NGOs, government agencies and investors.



IMPORTANT:

Before generating any page, establish one consistent Design System, Component Library and Information Architecture.



Do NOT start by creating random sections.



Build the project foundation first.



==================================================

PROJECT PURPOSE

==================================================



NUR.AI is an AI Camera Intelligence Platform.



It integrates with existing security cameras to help responsible professionals identify potential situations earlier and respond faster.



Artificial Intelligence never replaces teachers, rehabilitation specialists or caregivers.



AI only assists.



Humans always make the final decision.



This Human-in-the-Loop philosophy must remain consistent throughout the entire website.



Never describe NUR.AI as surveillance software.



Never describe it as facial recognition software.



Never claim medical diagnosis.



Never invent capabilities that are not explicitly described.



Use trustworthy and responsible language.

• Lucide Icons



Structure the project cleanly and consistently.



Use reusable components.
